# Productivity

Everyday workflow tools, not code-specific.

## Model-invoked

Model- or user-reachable (rich trigger phrasing so the model can reach for them).

- **[video-to-html](./video-to-html/SKILL.md)**: Turn a video (URL or local file) into one self-contained, responsive HTML page with light and dark themes: a step-by-step tutorial, a highlights summary, or a full summary of every topic covered. Needs the `watch` skill.
- **[confluence-read](./confluence-read/SKILL.md)**: Read a Confluence (Server / Data Center) page in full, including the images and attachments behind a 2FA wall, with a stored 2FA cookie that warns when it has expired.
